# DANN 

Production & inventory management for small-scale manufacturers.

## Branches
- `main` — protected. Merges only after `test` is validated. No direct work here.
- `test` — shared integration branch. Every role branch merges here first.
- `client-agents` — frontend + Claude-powered agents (owner: you)
- `backend` — core data model, DB, business logic (owner: backend lead)
- `research-data` — market research, pilot seed data (owner: research lead)
- `marketing-growth` — landing pages, QA, outreach (owner: marketing lead)

See the README.md inside each top-level folder for what belongs there and who owns it.
